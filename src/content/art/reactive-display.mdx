summary: |-
  This piece was a way for me to learn how to drive Hub75 LED panels as well as get to grips with TouchDesigner. 

  While I have been learning TouchDesigner it has quite a steep learning curve, and I have to give full disclosure that I used a TD MCP server to help build out the software side of this. Ultimately still a rewarding project and the time saved by using AI is undeniable

  I initially attempted to use an ESP32 to drive the panel but it wasn't able to maintain a strong enough wifi connection to get a decent framerate. The Pi was already running the camera so I decided to move everything over to the Pi. It is sending the camera feed to a Mac running TouchDesigner in another part of the house, which is doing the processing and sending the feed back to the Pi for displaying. There is some latency, but it is more than manageable for these effects.

  There are 4 effects (again - the power of AI)
  1. Finger tracking
  2. Hand tracking
  3. Head tracking
  4. Body silhouette tracking

  All in all quite a fun project, and now I have a pipeline set up by which I can iterate and drive all kinds of other effects. Audio reactivity is next on the list.
