## Overview

*Placeholder copy — replace with the project narrative.*

Paragami LED is a wall-mounted relief. A parametric crease pattern is generated in
Grasshopper, scored and folded from one continuous sheet, then mounted a fixed distance in
front of a 36 × 36 LED matrix. Light leaks through the folds so the geometry reads as glowing
edges rather than lit surfaces.

## Concept

The fold pattern is derived from a Miura-ori tessellation, distorted by a sine field so the
panel appears to buckle under an invisible pressure wave. Animations run along the same
field, so the light follows the fold logic.

## Electronics & control

Eight parallel data lines from the OctoWS2811 adapter drive 162 LEDs each. The panel
responds to USB MIDI so it can be played from a controller or sequenced alongside a live set.

| Parameter | Range        | MIDI CC |
| --------- | ------------ | ------- |
| Hue       | 0 – 255      | 1       |
| Wave speed| 0.1 – 4.0 Hz | 2       |
| Fold gain | 0 – 100 %    | 3       |
